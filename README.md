
# Spotify Song Popularity Prediction

## Project Overview
This is a Machine Learning project that predicts the popularity category of a song using its audio features and other available characteristics.

The project converts Spotify popularity scores into three categories:
- Not Popular (0–39)
- Moderately Popular (40–69)
- Popular (70–100)

These are project-defined categories.

## Project Objectives
- Understand and explore the Spotify dataset.
- Clean and preprocess the data.
- Perform Exploratory Data Analysis (EDA).
- Identify important song features.
- Build and evaluate Machine Learning classification models.
- Predict the popularity category of a new song.

## Dataset
The project uses the `songs_normalize.csv` dataset.

It contains song information and audio features such as:
- Danceability
- Energy
- Loudness
- Speechiness
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo
- Popularity
